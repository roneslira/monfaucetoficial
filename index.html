Airdrop Manager: This manager helps you organize and track cryptocurrency airdrops. Here's how to use it:

  • Add Airdrop: Click the "+ Add Airdrop" button to create a new project.
  • Subtasks: Inside each airdrop, add tasks (e.g., "Checkin", "Swap") with links and optional reminders. Click the airdrop name to open or close the subtask list.
  • Favorite: Click the star (★) to highlight important airdrops at the top of your column.
  • Status: Mark tasks as "Completed" or "Pending" by clicking "Status" – the menu stays open for multiple markings.
  • Edit: Use the ✏️ icon to change names, links, or reminders without recreating.
  • Manual Reset: Use "Manual Reset" to change all subtasks to "Pending" anytime; "Undo Reset" reverts this action if needed.
  • Export/Import: Save or load your list with the "Export" and "Import" buttons. Use "Export Auto" to save a JSON file on your computer and "Import File" to load it back.
  • Filters: Use "All", "Pending", or "Completed" to organize your view.

Data is encrypted and saved in your browser, resetting daily at midnight local time! For permanent backups, use "Export Auto" and store the file securely.
