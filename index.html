Sobre o MonFaucet

O MonFaucet é uma plataforma criada para distribuir tokens MON na Testnet Monad. Nosso objetivo é apoiar o ecossistema Monad oferecendo uma maneira fácil para os usuários fazerem claim de tokens e interagirem com nossos sponsors. Junte-se a nós para construir uma comunidade vibrante!

Termos de Uso

Ao usar o MonFaucet, você concorda em:
